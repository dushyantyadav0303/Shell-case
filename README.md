## About the Project
### **Shell case** - It is a 3D printable Halloween theme 3d model of candy Bowl in a Shape of a Seashell made in Blender. In which We can use for Halloween decoration.

## Why i made this
### So yeah, I built this Shell case For my Halloween decoration.
